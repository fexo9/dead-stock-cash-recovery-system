Two workbooks (English + Arabic RTL), each with 4 sheets: Setup, Velocity
Scorer, Markdown Optimizer, Action Planner. Plus docs: Recovery Playbook
(5-step sequence), Liquidation Channel Guide, quick-start guides (EN + AR),
worked examples (EN + AR), FAQ + limits (EN + AR), file-by-file inventory.

- **Velocity scoring**: every SKU flagged DEAD / SLOW / HEALTHY with a
  recommended action
- **Markdown Optimizer**: deepest discount before losing money, deepest
  discount that keeps your target margin, discount ladder, profit/loss verdict
- **Action Planner**: channel, target date, planned vs. actual cash recovered
- **Capacities**: 50 SKU rows on the Scorer, 60 on the Optimizer, 56 on the Planner
- **Sample data included** — fictional, clearly labeled — see it working instantly, then replace with yours
